# Project Skybound · 飛行跑車概念設計案

參考 Tesla Roadster「Rocket」飛行展示影片(2026-10)技術路線的飛行跑車全案概念設計。
冷氣體推進器環佈車身 + 車底 Venturi 抽氣風扇,雙模式(公路 / 跳躍飛行)。

> 概念工程研究,與 Tesla 無關。所有數值為設計目標,非量產承諾。

## 核心結論

- 飛行的物理本質是「跳躍」而非「巡航」:懸浮 1,750 kg 需 16.7 kN,燃料流量 25.4 kg/s,6 秒飛行消耗 ~170 kg 推進劑
- 冷氣體推進的消去律:ṁ = ff·At·Pc 與 At = F/(Cf·Pc) 相乘,室壓約去——燃料流量與室壓無關
- 推進劑排名:H2O2 單組元 8.6 > N2 冷氣體 7.2 > 雙組元 5.4 > 混合式 4.1(10 分制)
- v1 用 N2(法規友善),v2 升級 H2O2 單組元(isp ×2.1,推進模組 320 → 135 kg)
