# Project Skybound 飛行跑車概念設計案

**版本** v1.0 · **日期** 2026-10-21 · **性質** 概念工程研究(與 Tesla 無關,所有數值為設計目標)

---

## 0. 摘要

本設計案參考 Tesla Roadster「Rocket」飛行展示影片(2026-10)的技術路線——冷氣體推進器環佈車身、車底抽氣風扇、sub-1 秒加速——完成一台可短暫離地跳躍的雙模式(公路/飛行)跑車全案設計。核心結論:

- **飛行的物理本質是「跳躍」而非「巡航」**:冷氣體推進懸浮 1,750 kg 需 16.7 kN 推力、燃料流量 25.4 kg/s,6 秒飛行即消耗約 170 kg 推進劑。持續飛行在化學上不成立,這是設計邊界,也是設計特色。
- **車底 Venturi 抽氣風扇**解決「既要抓地又要離地」的矛盾:零速產生 2 g 下壓力,吸力強到可靜止倒掛。
- **推進劑選型**:v1 採 N2 冷氣體(法規最友善),v2 升級 H2O2 單組元(isp ×2.1,推進模組 320 → 135 kg)。

## 3. 推進系統

### 3.1 物理可行性驗算

| 參數 | 數值 | 備註 |
|---|---|---|
| 懸浮推力需求 | 16.7 kN | = 車重 1,750 kg × g |
| 單嘴推力(8 具) | 2.15 kN | 環佈構型 |
| N2 比衝 isp | ~69 s | γ=1.4、分子量 28 決定,冷氣體天花板 |
| 總燃料流量 | 25.4 kg/s | 與室壓無關(推導見 3.2) |
| 6 s 跳躍燃料 | ~170 kg | 含 15% 餘量 |
| COPV 氣瓶 | 13 × 50 L / 300 bar | 高壓複合氣瓶 |
| 系統總重 | ~320 kg | 佔車重 18% |
| 單次飛行時長上限 | ~10 s | 燃料限制 |

**消去律**:ṁ = ff·At·Pc 且 At = F/(Cf·Pc),兩式相乘室壓 Pc 約去——提高室壓只縮小噴嘴、提高儲存密度,不降低燃料消耗率。

**為什麼不用旋翼**:以車體尺寸產生 16.7 kN 升力,旋翼需約 1.2 MW 連續電功率,電池 10 分鐘耗盡且噪音巨大。冷氣體把能量以「壓力」儲存,瞬間功率密度極高、無外露旋翼——這正是展示影片設計的核心取捨。

### 3.2 噴嘴尺寸鏈(基準點:車重 1,750 kg、8 嘴、Pc 150 bar)

```
F = m·g = 17.2 kN
F_n = F/8 = 2.15 kN
A_t = F_n/(C_f·P_c) = 92 mm² → 喉徑 10.8 mm
ṁ = ff·A_t·P_c·8 = 25.4 kg/s(與 Pc 無關)
A_e/A_t = f(P_e/P_c) = 10.5:1 → 出口直徑 35 mm
m_prop = ṁ·t·1.15 = 152 kg(6 s,含餘量 170 kg)
n = m_prop / 12.5 kg/瓶 = 13 瓶(50 L / 300 bar)
```

噴嘴材料:鋁合金 CNC 即可(無燃燒、無熱負荷);電磁閥 2 ms 反應、100 Hz 推力解析度、每嘴獨立 PWM 調壓。

### 3.3 推進劑 trade-off(統一基準:16.7 kN × 6 s,含 15% 餘量)

| 方案 | isp | 燃料 | 乾重 | 點火 | 節流 | 重啟 | 總評/10 |
|---|---|---|---|---|---|---|---|
| N2 冷氣體 | 69 s | 170 kg | ~150 kg | 無 | 優 | 無限 | 7.2 |
| H2O2 單組元 | 145 s | 81 kg | ~55 kg | 無(催化) | 良 | ~50 次 | **8.6** |
| H2O2/煤油 雙組元 | 290 s | 41 kg | ~70 kg | 需要 | 中 | ~20 次 | 5.4 |
| N2O/HTPB 混合式 | 230 s | 51 kg | ~80 kg | 火工 | 差 | 差 | 4.1 |

- **混合式出局原因**:藥柱關機後不能重啟,做不到「跳躍→落地→再跳躍」cycle;姿態矢量需要毫秒級節流。
- **雙組元是性能迷思陷阱**:省下的燃料被雙貯箱、點火器、隔離閥的乾重吃回,且車載碳氫燃料 + 自燃點火幾乎不可能過道路法規。
- **H2O2 單組元勝出**:isp ×2.1、總系統 320 → 135 kg;催化分解無火焰點火程序;排氣為水蒸氣+O2,是四方案中唯一「像車不像火箭」的升級。需處理 90% H2O2 的氧化劑管制與 750°C 排氣材料(inconel 催化床與噴嘴)。

## 4. 車底抽氣風扇(Venturi)

| 參數 | 數值 |
|---|---|
| 目標靜止下壓力 | 2 g(33 kN) |
| 車底有效面積 | ~3.5 m² |
| 所需負壓差 | ~9 kPa |
| 風扇功率 | ~50 kW |
| 密封方式 | 柔性裙邊(參考 Chaparral 2J / Brabham BT46B 風扇車) |

風扇由電池供電,與推進劑系統互相獨立:燃料只管「離地」,風扇只管「貼地」。

## 5. 座艙人機介面

- **矩形 yoke + 線傳轉向**(steer-by-wire),路感回饋可調。
- **中央螢幕僅四顆實體觸鍵**:yoke / 煞車 / 推力 / 飛控。
- **三種儀表模式**:
  - road:一般儀表;
  - track:顯示 g 值與下壓力狀態,風扇全時運轉;
  - fly:姿態儀展開、高度/速度大字化,轉向輸入映射為推力矢量差動,非必要功能鎖定。

## 6. 系統架構

```
200 kWh 電池包 ──→ 三馬達 1,500 hp(前 1 + 後 2 扭力分配)
       └──→ 車底風扇 50 kW(Venturi 密封)

COPV 氣瓶組(300 bar N2 / H2O2 貯箱)
      → 推力歧管(電磁閥 ×8,2 ms)
      → 8 具冷氣體噴嘴(週邊環佈,矢量控制)

飛控電腦 ×4 冗餘(1000 Hz 控制迴路,多數投票)
      ← IMU ×3、光達高度計、GNSS
```

安全邏輯:飛行模式僅在封閉場地 + 地理圍欄內解鎖;燃料壓力低於懸浮需求 120% 時強制落地;任一飛控電腦異常即降級純電動模式。

## 7. 飛行包線(概念)

| 參數 | 數值 |
|---|---|
| 最大跳躍高度 | ~30 m(燃料限制) |
| 單次飛行時長 | < 10 s |
| 過渡點 | 8 m / 120 mph |
| 著陸緩衝 | 氣壓懸吊 + 風扇反推 |
| 解鎖條件 | 封閉場地 · 地理圍欄內 |

包線為硬邊界:系統在允許區外直接拒絕執行,而非僅警告。

## 8. 安全與法規

- N2 冷氣體 v1 無火源、排氣惰性,最接近「車載設備」定性;
- H2O2 v2 屬氧化劑管制品,需處理儲運與材料相容性(鈍化鋁合金);
- 所有飛行功能定位為封閉場地展示模式,不宣稱公路飛行合規;
- 四重冗餘飛控 + 多數投票 + 故障降級為設計硬要求,非選配。

## 10. 附錄:公式與常數

- 壅塞流:ṁ = At·Pc·√(γ/RT)·(1+(γ−1)/2)^(−(γ+1)/2(γ−1));N2 在 300 K 時 ff = 2.295×10⁻³
- 推力:F = Cf·Pc·At(Cf ≈ 1.55,海平面最佳膨脹)
- 膨脹比:Ae/At 由 Pe/Pc 等熵關係求得(Pc 150 bar 時 ≈ 10.5)
- 比衝:isp = F/(ṁ·g0);N2 ≈ 69 s,H2O2 單組元 ≈ 145 s
- 氣瓶:N2 於 300 bar / 300 K,壓縮因子 Z≈1.35,密度 ≈ 250 kg/m³;50 L 瓶約儲 12.5 kg
